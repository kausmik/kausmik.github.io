Little Slices
=============

This is an experimental space, inspired by Tale Foundry's
`old writing group <https://thetalefoundry.com/category/writing-group/>`_.
(Seriously, if you're a friend and you know where they've moved on to,
please tell me;
I think the Discord link in the posts on the linked site is expired.)
(Also, if you enjoy literary analysis, I think you'll find
`their YouTube channel <https://www.youtube.com/@TheTaleFoundry>`_ very fun.
They're also on `Nebula <https://nebula.tv/talefoundry>`_!)

You can find the rules I'll be following and a description of what little slices
are :doc:`here <./guidelines>`!
